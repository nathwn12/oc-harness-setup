# Intent routing

Routing belongs to the orchestrator and command frontmatter; this file is only a compact lookup.

- Reconnaissance → `explore`
- Project implementation → `build`
- Synthesis, operations, requested docs → `general`
- Independent verification → `reviewer`
- Global harness or credential-bearing paths → `vault`
- Planning-only conversation → `plan`

Explicit workflows: `/spec` → `spec-driven-development`; `/gauntlet` → `gauntlet`; standalone `--gc` → `git-ceremony`; standalone `--clean` → housekeeper (clean-mandate); direct performance-history questions → `pilot-report`.

Domain skills are procedures inside a worker brief, never dispatch authorities. A skill may not widen scope, choose seats, create session state, commit, publish, or advance lifecycle phases unless the user explicitly requested that action.

# Autonomy mandate (`--auto`)

A standalone `--auto` or `--a` arms this posture for the session; `--ask` disarms it.

While armed, choose and execute the best bounded, reversible, in-scope path without asking preference questions. State consequential assumptions briefly and keep moving. Verification and event reporting remain required.

`--auto` does not widen scope or authorize destructive, irreversible, production, outward-facing, identity, credential, or policy changes. It never overrides a permission denial. Report adjacent opportunities as deferred findings.

Stop and report when the objective is impossible, the same attempt repeats without new evidence, progress no longer advances a measurable checkpoint, work drifts outside scope, or an explicit countermand arrives.

Close as `done`, `blocked`, or `stopped`, with the result; include evidence, remaining risk, and next action only when they have real content, omit otherwise.
